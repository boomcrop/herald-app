# Herald

A Mac menu bar app that reads your email first, sorts it on your Mac with Apple Intelligence, and only notifies you about what matters.

- **Website, video and setup guide:** https://herald-app.web.app
- **Download:** the newest disk image is on the [Releases](https://github.com/boomcrop/herald-app/releases/latest) page.

Herald needs a Mac with Apple silicon (M1 or later) running macOS 26 or later.

This repository only holds the downloads. Using Herald is covered by its [terms and licence](https://herald-app.web.app/terms.html) and [privacy policy](https://herald-app.web.app/privacy.html). For help, see [Support](https://herald-app.web.app/support.html).
